# 🚢 Titanic Disaster Analysis

## About Project
This project focuses on analysing the Titanic disaster dataset using Python. The dataset is collected from Kaggle to explore passenger survival patterns and identify factors affecting survival.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code

## Dataset
Source: [Kaggle Titanic Dataset](https://www.kaggle.com/competitions/titanic/data)

## Analysis Includes
- Gender-wise survival analysis
- Age-wise survival analysis
- Passenger class comparison
- Data cleaning and visualisation

## Objective
To gain practical knowledge of Python, Data Analysis and Exploratory Data Analysis (EDA).
